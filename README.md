#Hybrid Cucumber Framework
Hybrid Automation Framework built with Selenium WebDriver, Java, TestNG, Cucumber BDD,Maven and Jenkins CI/CD
## Tech Stack
- Java
- Selenium WebDriver
- Cucumber BDD
- TestNG
- Maven
- Page Object Model (POM)
- Jenkins - Continuous Integration
## Project Structure
- src/test - Test Cases, step Definitions, Page Objects
- pom.xml - Maven dependencies
- testng.xml - TestNG Suite

## How to run locally
''' bash
mvn test
